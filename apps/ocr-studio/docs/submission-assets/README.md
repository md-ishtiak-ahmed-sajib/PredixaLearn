# PredixaLearn submission media checklist

Store only deliberately selected, permission-cleared submission media in this
directory. Do not add real exam papers or student information unless their
distribution is authorized.

## Required captures

| Suggested filename | Frame | Purpose |
| --- | --- | --- |
| `01-source-page.png` | Difficult permitted source page | Establishes the problem. |
| `02-baseline-output.png` | Ordinary extraction of the same page | Shows the structural gap fairly. |
| `03-convert.png` | PredixaLearn Exam Paper workflow | Shows an understandable entry point. |
| `04-evidence-review.png` | Result beside source page, confidence, and warning | Proves traceability and responsible uncertainty. |
| `05-analysis.png` | Source-linked topic, marks, difficulty, and review state | Demonstrates Past Paper Intelligence. |
| `06-benchmark.png` | Measured real-paper report with limitations | Supports impact claims. |
| `07-codex-evidence.png` | Completed evidence record and tests | Shows responsible Codex use. |

## Recording rules

- Use the completed, pre-warmed Judge Demo result when a live full OCR run would
  consume the recording window; disclose any time cut on screen.
- Redact personal data, candidate numbers, school identifiers, and source files
  without distribution permission.
- Keep the final video under the competition’s length limit and retain an
  unedited source recording for review.
- Do not add a benchmark frame until it contains permission-cleared, manually
  verified measurements and documented limitations.
